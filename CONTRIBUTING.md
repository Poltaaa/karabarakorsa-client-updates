# Katkıda Bulunma

1. Depoyu fork edin ve kısa isimli bir dal oluşturun.
2. Değişikliklerinizi küçük ve anlaşılır commit'lerle yapın.
3. `npm ci` ve `npm run verify` çalıştırın.
4. Arayüz değişikliklerini Windows üzerinde görsel olarak kontrol edin.
5. Pull request içinde sorunu, çözümü ve test adımlarını açıklayın.

## Kurallar

- Gerçek hesap bilgisi, oturum anahtarı, proxy parolası veya kişisel günlük eklemeyin.
- Yeni ağ adreslerini ve neden gerekli olduklarını PR açıklamasında belirtin.
- Kullanıcı verisini dışarı gönderen telemetri eklemeyin.
- Sunucu kurallarını veya erişim kontrollerini atlatmaya yönelik özellik eklemeyin.
